# Yene Birr 3.0 (የኔ ብር)

Ethiopian calendar personal finance tracker.

## 3.0 highlights
- **Category Ranking** analysis (pie + ranked list with %, amount, bill count, progress bars)
- Month navigator on Analysis (no more month-to-month bar comparison)
- Green default theme + Noir dark theme
- Calendar weekday fixed (አርብ = Friday)
- Ledger day groups with daily totals
- Edit transactions & accounts
- Green splash + Developed by Melaku Sisay

## Build APK
Push to GitHub → Actions → Build Android APK → download `yenebirr-debug-apk`
